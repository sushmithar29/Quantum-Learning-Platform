Foundation Concept

Dirac Bra-Ket Notation

Introduced by Paul Dirac in 1939, this algebraic grammar represents state vectors as kets $|ψ⟩$ and their dual conjugate transpose row vectors as bras $\langleφ|$.

Ket (Column):  |ψ⟩ = [c₀, c₁]ᵀ
Bra (Row Dual): ⟨φ| = (|φ⟩)† = [d₀*, d₁*]
Bracket (Inner Product): ⟨φ|ψ⟩ = d₀*c₀ + d₁*c₁
🎓 Key Takeaways:
  • Orthonormality: $\langle 0|0\rangle = 1$, $\langle 1|1\rangle = 1$, while $\langle 0|1\rangle = 0$ (orthogonal).
  • Born Rule: Probability of measuring state $|\phi\rangle$ from state $|\psi\rangle$ is $P = |\langle\phi|\psi\rangle|^2$.
  • Outer Product $|\psi\rangle\langle\phi|$: Creates an operator or density matrix mapping states to states.

💡 Geometric Meaning
The inner product ⟨φ|ψ⟩ calculates the projection of vector |ψ⟩ onto vector |φ⟩. If ⟨φ|ψ⟩ = 0, the states are mutually exclusive and distinguishable in a single measurement.
Completeness Relation: |0⟩⟨0| + |1⟩⟨1| = I (Identity operator).
