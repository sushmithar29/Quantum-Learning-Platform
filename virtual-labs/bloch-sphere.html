🎯 Section 01

Experiment Aim

To visualize and manipulate single-qubit quantum states as points on the unit Bloch sphere S², apply discrete unitary quantum gate transformations (X, Y, Z, H, S, T) which correspond to specific geometric rotations in SU(2), perform continuous Euler angle rotations Rx(θ), Ry(θ), Rz(φ) via interactive sliders, and establish the correspondence between complex probability amplitudes and 3D Cartesian Bloch coordinates.

📖 Section 02

Theoretical Foundations

1. Qubit State Space and Bloch Representation

Any single-qubit pure state is a unit vector in C², parameterized up to global phase by two real angles θ (polar) and φ (azimuthal):

|ψ⟩ = cos(θ/2)|0⟩ + e^(iφ)sin(θ/2)|1⟩

Bloch Cartesian coordinates:
x = sin(θ)cos(φ), y = sin(θ)sin(φ), z = cos(θ)

|0⟩ → north pole (0,0,1), |1⟩ → south pole (0,0,-1)
|+⟩ = (|0⟩+|1⟩)/√2 → (+x axis), |-⟩ → (-x axis)

2. Gates as SO(3) Rotations

Every single-qubit unitary gate U ∈ SU(2) corresponds to a rotation on the Bloch sphere:

• Pauli-X: 180° rotation about x-axis → |0⟩ ↔ |1⟩
• Pauli-Y: 180° rotation about y-axis → |0⟩ → i|1⟩, |1⟩ → -i|0⟩
• Pauli-Z: 180° rotation about z-axis → relative phase π on |1⟩
• Hadamard H: 180° rotation about (x+z)/√2 axis
• Phase S: 90° rotation about z-axis
• Phase T: 45° rotation about z-axis

General rotation: Rn̂(θ) = cos(θ/2)·I − i·sin(θ/2)·(nx·X + ny·Y + nz·Z)

3. Mixed States and Bloch Ball

Pure states reside on the sphere surface |r| = 1. Mixed states (introduced by decoherence or tracing) reside inside the Bloch ball |r| < 1. The completely mixed state ρ = I/2 sits at the origin.

ρ = (I + r·σ)/2, where r = (⟨X⟩, ⟨Y⟩, ⟨Z⟩)
🎓 Section 03

Learning Objectives

  • Map complex two-dimensional state vectors (α, β) to 3D Cartesian Bloch coordinates (x, y, z) using polar and azimuthal angles θ and φ.
  • Apply discrete quantum gates (X, Y, Z, H, S, T) and interpret each as a specific geometric rotation on the Bloch sphere surface.
  • Perform continuous Euler angle rotations Rx(θ), Ry(θ), Rz(φ) using interactive sliders and observe the Bloch vector trajectory.
  • Understand why global phases e^(iγ) are physically unobservable (they don't change the Bloch vector position).
  • Analyze how decoherence and environmental noise shrink the Bloch vector from the sphere surface toward the origin (mixed states).
📋 Section 04

Step-by-Step Procedure

01

Initialize Qubit State

Navigate to the Simulation tab. The Bloch sphere displays the initial ground state |0⟩ at the north pole (z = +1). Use the state preset buttons to load common starting states.

02

Apply Gate Transformations

Click any gate button (H, X, Y, Z, S, T) in the Gate Panel. The Bloch vector animates smoothly to its new position showing the rotation axis and resulting state.

03

Perform Continuous Rotations

Use the Rx(θ), Ry(θ), Rz(φ) sliders to apply arbitrary rotation angles around each axis. Observe the continuous trajectory traced by the Bloch vector on the sphere surface.

04

Record State Coordinates

Read the live state vector display showing α, β amplitudes and their phases. Note the corresponding (x, y, z) Bloch coordinates and measurement probabilities P(|0⟩) and P(|1⟩).

05

Compare Theory with Simulation

Verify that the computed Bloch coordinates from theory (x = sin θ cos φ, y = sin θ sin φ, z = cos θ) match the live coordinates displayed during the simulation.

👁️ Section 06

Observation Analysis

Key phenomena observable during the Bloch sphere simulation:

A

Superposition Equator

All states on the equatorial great circle (θ = π/2) represent maximum superposition states with equal probability P(|0⟩) = P(|1⟩) = 50%, differing only in relative phase φ.

B

Hadamard Geometry

The Hadamard gate performs a 180° rotation about the (x+z)/√2 diagonal axis, swapping the north and equatorial +x poles: H|0⟩ = |+⟩, H|+⟩ = |0⟩. Applying H twice returns to identity.

C

Phase Invariance of Measurement

The Z gate applies a 180° z-rotation: |+⟩ → |-⟩. Though the Bloch vector flips along the equator, P(|0⟩) remains unchanged at 50% — demonstrating that z-basis measurement cannot detect relative phase.

✍️ Section 09

Assignments

A1

Construct Arbitrary State via Euler Rotations

Using only the Ry and Rz sliders (no X/Y/Z gates), prepare the state |ψ⟩ = (√3/2)|0⟩ + (1/2)|1⟩ (which lies at θ = 60° on the Bloch sphere). Record the slider values and verify by comparing P(|0⟩) = 75%.

A2

Gate Sequence: T gate Power Series

Starting from |+⟩, apply the T gate 8 consecutive times. Predict and verify using the simulation that T⁸ = Z (i.e., 8 × 45° = 360° → identity, but since T acts on |1⟩ component, T⁴ = Z). Document each intermediate Bloch vector position.
