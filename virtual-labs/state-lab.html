🎯 Section 01

Experiment Aim

To prepare arbitrary single-qubit quantum states |ψ⟩ = α|0⟩ + e^(iφ)β|1⟩ through interactive manipulation of probability amplitudes α, β (subject to normalization |α|² + |β|² = 1) and relative phase φ. The experiment computes expectation values ⟨σ_x⟩, ⟨σ_y⟩, ⟨σ_z⟩ of the Pauli operators, reconstructs the 2×2 density matrix ρ, and visualizes the state as a point on the Bloch sphere, demonstrating how complex amplitudes encode physically measurable quantum information.

📖 Section 02

Theoretical Foundations

1. Qubit State Parameterization

A single qubit state |ψ⟩ lives in a 2D complex Hilbert space C². Using the Bloch parameterization up to global phase:

|ψ⟩ = α|0⟩ + β·e^(iφ)|1⟩, α,β ∈ ℝ≥0, α² + β² = 1

Equivalently: α = cos(θ/2), β = sin(θ/2), φ ∈ [0, 2π)

Global phase: e^(iγ)|ψ⟩ is physically identical to |ψ⟩
Relative phase φ: physically observable via conjugate-basis measurements

2. Density Matrix and Expectation Values

ρ = |ψ⟩⟨ψ| = [[|α|², α·β·e^(-iφ)], [α·β·e^(iφ), |β|²]]

Pauli Expectation Values (Bloch vector components):
⟨σ_z⟩ = Tr(ρ·Z) = |α|² − |β|² = cos(θ)
⟨σ_x⟩ = Tr(ρ·X) = 2αβ·cos(φ) = sin(θ)cos(φ)
⟨σ_y⟩ = Tr(ρ·Y) = 2αβ·sin(φ) = sin(θ)sin(φ)

3. Normalization and State Purity

Normalization: |α|² + |β|² = 1 (Born rule constraint)
Purity: Tr(ρ²) = 1 for pure states, Tr(ρ²) < 1 for mixed states
von Neumann Entropy: S(ρ) = −Tr(ρ·log₂(ρ)) ∈ [0, 1]
S = 0 (pure state), S = 1 (maximally mixed)
🎓 Section 03

Learning Objectives

  • Verify normalization |α|² + |β|² = 1 for physical quantum states and understand how it constrains the state space.
  • Understand why global phases e^(iγ) are physically unobservable (do not affect any measurement outcomes) while relative phase φ does.
  • Compute Pauli expectation values ⟨σ_x⟩, ⟨σ_y⟩, ⟨σ_z⟩ and relate them directly to amplitude and phase parameters.
  • Reconstruct the full 2×2 density matrix ρ from state parameters and identify diagonal vs off-diagonal coherence terms.
  • Visualize how changing amplitude vs changing phase produces different effects on the Bloch sphere position and measurement outcomes.
📋 Section 04

Step-by-Step Procedure

01

Set Amplitude α

Use the α slider to set the probability amplitude of |0⟩. The system automatically computes β = √(1−α²) to maintain normalization. P(|0⟩) = α² is shown in real time.

02

Adjust Relative Phase φ

Use the phase slider to set the relative phase φ ∈ [0°, 360°]. Observe that P(|0⟩) and P(|1⟩) remain unchanged, but ⟨σ_x⟩ and ⟨σ_y⟩ change, showing the phase is physically real in conjugate bases.

03

Read Expectation Values

Observe ⟨σ_x⟩, ⟨σ_y⟩, ⟨σ_z⟩ in the results panel. These are the Cartesian Bloch coordinates and equal the measurement outcomes averaged over many shots in X, Y, Z bases respectively.

04

Inspect Density Matrix

The 2×2 density matrix ρ is displayed with both real and imaginary components. Note the diagonal |α|² = P(|0⟩) and |β|² = P(|1⟩), and off-diagonal coherence terms α·β·e^(±iφ).

05

Verify Global Phase Invariance

Set any α and φ. Record all measurement observables. Then apply any global phase to observe that all ⟨σ_x⟩, ⟨σ_y⟩, ⟨σ_z⟩ remain identical — confirming global phase is unphysical.

👁️ Section 06

Observation Analysis

A

Amplitude Encodes Population

|α|² and |β|² directly encode the probability of measuring |0⟩ and |1⟩ in the Z-basis. These populations can be measured by accumulating many Z-basis shots. Changing α changes the polar angle θ of the Bloch vector.

B

Phase Encodes Coherence

The relative phase φ encodes the off-diagonal coherences ρ₀₁ = α·β·e^(-iφ) of the density matrix. These require X-basis or Y-basis measurements to detect. This is why quantum state tomography needs measurements in multiple bases.

C

Maximum Coherence

Off-diagonal coherences |ρ₀₁| = α·β are maximized when α = β = 1/√2 (equal superposition). This corresponds to any state on the Bloch sphere equator, regardless of phase φ.

✍️ Section 09

Assignments

A1

State Identification from Bloch Coordinates

Given that a qubit has Bloch coordinates (x=0.5, y=0.5, z=0.707), determine the values of α, β, and φ. Verify using the simulator by matching the displayed ⟨σ_x⟩, ⟨σ_y⟩, ⟨σ_z⟩ to the target values.

A2

Phase Sensitivity Demonstration

Fix α = 1/√2 (equal superposition). Sweep φ from 0° to 360° in steps of 45°. Record ⟨σ_x⟩ and ⟨σ_y⟩ at each step. Verify that ⟨σ_x⟩ = cos(φ) and ⟨σ_y⟩ = sin(φ), and P(|0⟩) = 50% throughout.
